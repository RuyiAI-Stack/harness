# Two Types of Execution Modes

English | [Chinese](1-introduction.zh.md)

This Harness has two usage modes: One is [**Interactive Agent**](./2-interactive-agent.md), used similarly to local harnesses such as Codex and Claude Code; compared with a general-purpose harness, its advantage is that it adds team members and integrates this project’s development characteristics. The other is [**Cloud Agents**](./3-cloud-agents.md), deployed on servers to run long-term and shared by organization members; suitable scenarios include periodically syncing repositories, and invoking it via GitHub/Zulip and other hooks for ephemeral-like workflows.
