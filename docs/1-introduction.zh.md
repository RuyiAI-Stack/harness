# 两种执行模式

[English](1-introduction.md) | 中文

本 Harness 提供两种使用模式：一种是 **[Interactive Agent](./2-interactive-agent.md)**，用法类似 Codex、Claude Code 等本地 harness；相较通用 harness，它融入了团队成员协作，并贴合本项目的开发特性。另一种是 **[Cloud Agents](./3-cloud-agents.md)**，部署在服务器上长期运行、由组织成员共用；适合定期同步仓库，可以通过 GitHub / Zulip 等 hook 触发类 ephemeral 的工作流。
